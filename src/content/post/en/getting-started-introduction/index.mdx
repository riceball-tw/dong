Welcome to the **Dong Blog**! This theme is designed for developers who want a high-performance, aesthetically pleasing, and feature-rich blog powered by Astro.

<PostImage src={Logo} alt="Dong Blog Logo" title="The official logo of Dong Blog" />

## Why Dong Blog?

Dong Blog is built with a focus on:

- **Performance**: Optimized for speed and low bundle size.
- **Developer Experience**: Built with Astro, MDX, and Tailwind CSS.
- **Rich Components**: Includes custom components like Sidenotes, Video embeds, and interactive elements.
- **i18n Support**: Ready for multiple languages out of the box.

## Core Features

This theme comes packed with features that make your blogging experience seamless:

1.  **MDX Support**: Use React components directly in your Markdown files.
2.  **Content Collections**: Fully typed content schemas for safety and reliability.
3.  **Tailwind CSS**: Easily customize styles with the utility-first CSS framework.
4.  **Responsive Design**: Looks great on every device, from mobile to desktop.
5.  **SEO Optimized**: Built-in JSON-LD, sitemaps, and optimized metadata.
